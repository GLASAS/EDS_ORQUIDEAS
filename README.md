# ⛽ FuelManager - Sistema de Gestión para Estación de Servicio

Sistema web desarrollado con **Google Apps Script** y **Google Sheets** para la administración integral de estaciones de servicio.

## 🚀 Características Principales
* **Dashboard Dinámico:** Indicadores visuales tipo tanque/batería con niveles de autonomía (Full, Medio / 3 días, Bajo).
* **Filtros de Ventas:** Visualización de métricas por Hoy, Día Anterior, Semana y Mes.
* **Control de Inventarios:** Monitoreo en tiempo real de combustibles y productos de tienda.
* **Caja y Turnos:** Apertura, control de ingresos por medios de pago, gastos operativos y cierre de caja con arqueo.
* **Gestión de Usuarios:** Autenticación segura con validación por fecha de expedición de cédula.
